A Linux desktop that sets up your privacy, and shows you where it stands.

ArkaOS turns on common privacy settings for you, tells you plainly whether each one is in place, and keeps your previous system on disk when it updates. It's built on Fedora and KDE Plasma.

What it is

Privacy settings, already on

Settings you'd normally look up and change by hand are set when the system starts, and checked again while it runs. If one stops being in place, ArkaOS says so.

Updates that wait for you

A new version is prepared next to the one you're using and takes over only when you restart. Updates never restart your computer on their own, and the previous version is kept on disk. If a new version fails its start-up checks, or doesn't start at all, ArkaOS tries it three times and then goes back to the previous version by itself.

Plain answers, no score

The Privacy dashboard lists each setting as Configured or Needs attention and when it was last checked. It never gives you a percentage or says you're "protected".

Working with your files

Right-click a file in Dolphin, or drag it and press a key for a ring of choices. Each job runs in a sandbox with no network access, and the result is a new copy next to the original. Nothing is overwritten.

Convert to another formatPictures to PNG, JPEG, WebP or PDF. A PDF to one picture per page, or to a Word file (the layout will differ). Sound to MP3, FLAC, WAV, Ogg, Opus or AAC. Video to MP4, MKV or WebM, or just its sound. Word and Excel files to PDF.
Tested in a VM
Make smallerPictures, sound, video and PDFs, at Light, Medium or Strong, or to fit under 10 MB or 25 MB. A copy is kept only if it really is smaller. The levels and size targets are new.
Partly tested
Remove hidden detailsSaves a copy without the details you can't see, such as where a photo was taken or who wrote a document, using mat2. It removes what mat2 knows about, not what is in the picture or sound itself.
Tested in a VM
Edit a pictureCrop, black out parts, annotate (pens, arrows, boxes, highlights and text), add a background, rotate. Black out replaces the pixels in the copy, so what was under a box can't be read back from it. Annotate is new.
Partly tested
Find private textReads the words in a picture on this computer and suggests boxes over text that looks like an email address, a phone number or a card number, for you to check and black out. It can miss some, so look before you save.
Seen working in a VM
Read the text in a picture or PDFSaves the words it finds as a text file. Text recognition makes mistakes, more so on poor scans.
Checked with tests
Edit sound and videoTrim, split in two, join several into one, and bleep out parts, with playback so you can hear the part before saving. Trimmed, split and bleeped copies keep the file's hidden details; use Remove hidden details if you don't want them.

The privacy settings

What each one does, in plain words, and how far we've tested it.

Encrypted DNSWebsite-name lookups are sent encrypted (to Quad9). On a network that blocks this, you can allow unencrypted lookups on that network only, and the dashboard says so (this option is new and still being tested).
Tested in a VM
Private network addressUses a random hardware (MAC) address on networks, so networks see a different device ID.
Tested in a VM
Computer nameSetup asks for a name for this computer. The default, "arka", is the same on every ArkaOS computer, so the name alone doesn't point to your computer. A name you choose yourself might.
Tested in a VM
Temporary IPv6 addressesUses IPv6 addresses that change over time.
Tested in a VM
Sandboxed browserFirefox runs in a sandbox that can see your Downloads folder but not the rest of your files.
Tested in a VM
FirewallRejects connections other computers try to open to this one.
Tested in a VM
Kernel hardeningStricter memory and kernel settings that make some attacks harder.
Tested in a VM

"Configured" means a checked setting is in place. It doesn't mean you can't be tracked: websites, accounts and apps can still identify you.

What we can show, and what we can't

Every item sits in exactly one column. We move something left only after testing it.

Tested

  • The privacy settings above marked "Tested in a VM"
  • Setup with a light or dark look, then your desktop
  • Read-only system files at runtime
  • Going back to the previous version on its own after a broken update, keeping a good update, and going back by hand with one command (in a VM on 11 October 2026; the first two also on one real laptop on 12 October 2026)
  • Booting from USB on one laptop (an earlier version)
  • Converting, shrinking and cleaning files, and the format and edit wheels (in a VM)

Being tested

  • Updates and going back on real laptops
  • More real laptops
  • The newer file tools: annotate, split, join, bleep, and reading text from pictures
  • arka-pulse, which watches system health locally. Its predictions are estimates and it takes no action on its own.

Not yet

  • A downloadable installer. One with disk encryption on by default is built and works in a VM, but isn't published yet.
  • Secure Boot with ArkaOS's own keys
  • Support for a wide range of hardware
  • Anonymity of any kind. ArkaOS doesn't hide who you are online.
